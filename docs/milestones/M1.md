# M1 — PX4 + ROS2 + Gazebo Runtime

状态：DONE

## 范围

建立可复现的 PX4 SITL、ROS 2、Gazebo 和 uXRCE-DDS 本地仿真环境。M1 不实现
LLM Planner 或 Flight Skill。

## 版本决策

当前主机：

```text
Ubuntu 24.04.4 LTS
Python 3.12.3
uv 0.12.11
```

M1 目标技术栈：

```text
OS              Ubuntu 24.04 LTS
ROS2            Jazzy Jalisco
Gazebo          Harmonic
PX4             v1.16.2 / 54f0455ffcd755534539a7cf33a09a20bf71d29d
Vehicle         x500 multicopter
Middleware      uXRCE-DDS
Python          3.12
Package manager uv
```

选择理由：

- PX4 ROS 2 文档推荐 Ubuntu 24.04 使用 ROS 2 Jazzy。
- Gazebo Harmonic 提供 Ubuntu Noble Binary Package，并与该 ROS 2 路线匹配。
- 当前主机已经是 Ubuntu 24.04；除非后续阻塞，否则不切换到 Ubuntu 22.04/Humble。

## 测试

- `python scripts/runtime/check_runtime_health.py`
- `make px4_sitl gz_x500`
- `MicroXRCEAgent udp4 -p 8888`
- `ros2 topic list`
- 确认至少一个 PX4 Topic 对 ROS 2 可见。

## 已知风险

- PX4、Gazebo 与 ROS 2 Package 版本可能存在安装顺序兼容问题。
- Agent/Client 端口或环境加载错误会导致 uXRCE-DDS Topic 不可见。
- CI 不要求 Gazebo GUI，优先使用 Headless 启动。

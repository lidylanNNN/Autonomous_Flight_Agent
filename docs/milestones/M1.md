# M1 — PX4 + ROS2 + Gazebo Runtime

Status: IN_PROGRESS

## Scope

Build a reproducible local simulation runtime for PX4 SITL, ROS 2, Gazebo, and
uXRCE-DDS. M1 does not implement the LLM planner or flight skills.

## Version Decision

Current host:

```text
Ubuntu 24.04.4 LTS
Python 3.12.3
uv 0.12.11
```

M1 target stack:

```text
OS              Ubuntu 24.04 LTS
ROS2            Jazzy Jalisco
Gazebo          Harmonic
PX4             v1.16.2 / 54f0455ffcd755534539a7cf33a09a20bf71d29d
Vehicle         x500 multicopter
Middleware      uXRCE-DDS
Python          3.12
Package manager uv
```

Reasoning:

- PX4 ROS 2 documentation recommends ROS 2 Jazzy on Ubuntu 24.04.
- Gazebo Harmonic provides Ubuntu Noble packages and is the matching Gazebo
  release for ROS 2 Jazzy in this project.
- The repository host is already Ubuntu 24.04, so M1 should not target Ubuntu
  22.04 / Humble unless a later blocker forces a container fallback.

## Deliverables

- Runtime setup guide.
- Local runtime health check script.
- Pinned environment manifest updated for M1.
- PX4 source checkout and fixed commit.
- ROS 2 Jazzy installation.
- Gazebo Harmonic installation.
- uXRCE-DDS agent available.
- PX4 SITL x500 can start.
- ROS 2 can observe PX4 DDS topics.

## Tests

Planned:

- `python scripts/runtime/check_runtime_health.py`
- `make px4_sitl gz_x500`
- `MicroXRCEAgent udp4 -p 8888`
- `ros2 topic list`
- Verify at least one PX4 topic is visible from ROS 2.

## Known Risks

- PX4, Gazebo, and ROS 2 package versions may require small install-order fixes.
- uXRCE-DDS topic visibility can fail if agent/client ports or environment
  sourcing are wrong.
- Gazebo GUI is not required for CI; headless startup is preferred.

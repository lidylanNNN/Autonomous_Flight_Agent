状态：IN_PROGRESS

## 范围

在统一 `FlightExecutionInterface` 边界后实现确定性的 Takeoff、GoTo、Hold、RTL 和 Land。
M3 由脚本和强类型 Fixture 驱动，不引入 LLM Agent，也不重复实现 M4 Safety Policy。

## 当前决策

- `FlightExecutionInterface` 只接受 `ApprovedSkillCommand`，原始 Proposal 不得直接下发。
- 执行开始前已有 `execution_id`，取消操作可以定位在途命令。
- Skill 参数使用 Pydantic Model，并拒绝未知字段、NaN 和无穷数。
- 业务边界使用正高度，PX4 Adapter 负责转换为 NED 向下轴数值。
- 记录 PX4 ACK，但不把它当作任务步骤最终成功的证据。
- Registry 的 Required State 是供 M4 使用的元数据，不是内嵌 Safety Logic。

参见 `docs/adr/ADR-001-approved-skill-runtime-boundary.md` 和
`docs/contract_specs/skill_contract.md`。

# M2 — World State 与 Trace 基础

状态：DONE

## 完成日期

2026-09-17

## 范围

建立供后续 Skill、Safety、Verifier、Recovery 和 Evaluation 使用的确定性状态与
Trace 基础。M2 不发送飞行命令，也不实现 LLM Agent。

## 交付物

- 符合项目 NED Contract 的强类型 `WorldState`。
- PX4 ROS 2 状态订阅与多 Topic 聚合。
- 分 Topic 的 Freshness 和过期状态检测。
- 带符号测试与往返测试的 NED/ENU 转换函数。
- 根据必需 Topic、位置、电池和 Failsafe 派生的 Runtime Health。
- JSON Lines 格式的 WorldState Recorder。
- 可按记录序号、`state_id` 和记录时间查询的强类型 Trace Replay。
- Runtime 启动脚本、Topic 冒烟测试和 Trace 回放命令。

## Evaluation Report

M2 只产出基础设施证据，不产出任务级成功率。Frozen Mission Set Evaluation 延后到
M8–M10。

## 已知 Bad Case

- 没有地面站的 SITL 会报告 `gcs_connection_healthy=false`；该状态会被记录，但当前
  不参与 `runtime_healthy` 计算。
- PX4 建立 Home 前 `home_valid=false`；M3 的 RTL 必须要求 `home_valid=true`。
- M2 不发送命令，因此没有生成真实 ACK；ACK 关联属于 M3 交付项。

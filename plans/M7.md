# M7 — Flight Agent 系统 Eval（一周）

状态：2026-11-17 按用户决定建立。新 M7 只做系统性能评测，不恢复旧 M7 反馈修正阶段；不与 M7-S 在途安全专项混称。尚未实施或产生指标。

## 1. 现状

`eval_harness` 仍只有占位，现有 M4/M5 是指定场景运行证据。[M6](M6.md)负责视觉接入与功能 test，当前也尚未完成。不能以两份计划存在就声明视觉可用或 eval 已完成。

M7 必须在 [M6 T1](M6.md#t1先证明场景有用)通过、T07 交接后开始；复用真实主入口、相机/检测工具、已有进程与采集设施，不另写业务系统或再搭场景平台。

## 2. 目标

一周内衡量 M6 的有用场景“多有用”：在固定多任务集合上自动运行、从实际状态和媒体判分、汇总普通/未见/扰动场景完成率，并输出相对同工具基线的差值、样本量和区间。

主输出为 `task_success_rate`、`unseen_success_rate`、`perturbed_success_rate`、`improvement_pp`，同时附 numerator/denominator、95% 区间、耗时、成本、安全违规和覆盖率。定义只在[测评设计](../docs/eval_doc/v1_evaluation.md)维护，M7 不重新定义评分公式。

所有 X 由运行产生，允许零或负提升；没有独立测试集不报未见成绩，正确停止不冒充业务目标完成。

## 3. 范围与约束

- 固定一套 M6 工具与简单世界，先少量业务任务族和重复；不是全模型/架构 Benchmark 平台。
- B0/B1 均具备相同相机、检测与飞行动作。候选至多修改一处有 Dev 证据支持的 Agent prompt/配置，不训练工具、不放宽 Safety；较大业务或架构修复留后续。
- 分开普通、未见、环境扰动与工具故障组，必要的交叉组实际跑到才报告；每组列任务族和次数。已有 Dev 不能改名成未见，按[拆分规则](../docs/eval_doc/split_freeze_rules.md)保持任务族隔离。
- 环境扰动只复用 M6 的一种布局/遮挡变化；故障只做一种可控通信延迟/不可用，不建通用注入引擎。前者有实际场景/画面证据，后者有实际边界事件记录。
- 返回值替身只验证评分和错误归因，不能混入真实模型/SITL 的系统成绩；工具效果问题不从目标完成率分母删除。
- 最终集和运行次数预先固定，只在 Dev 调整 B1；保留失败和缺失配对。小样本区间只作探索性结果，不据此宣称稳定泛化。
- 日志、费用和预算保护沿用现有机制；运行计划超出额度时先缩小并注明范围，不自动扩额、清零或只挑成功结果。

## 4. 一周时间盒与最小可评审批次

一周按 5 个有效开发日、每日约 6 小时安排。含每批验证/说明，不含外部等待；这是用户设定的交付时间盒，不保证所有环境故障均能在其中解决。每批单一目标，默认不超过 300 行语义改动，接口/结构变化按 AGENT.md 评审。

### 4.1 协议与真实运行（第 1 日至第 2 日前半，1.25 日）

| 批次 | 唯一目标/位置 | 依赖 | 时间盒/日 |
|---|---|---|---:|
| E01 | 固定实验协议、任务族/判据、种子与次数，保存同工具 B0 快照及独立未见集合 | M6 T07；现行数据/拆分契约 | 0.5 |
| E02 | Runner 复用 M6 设施，从实际入口跑一个视觉任务并保存 Episode | E01 | 0.75 |

### 4.2 真实结果判分与报告（第 2 日后半至第 3 日前半，1.25 日）

| 批次 | 唯一目标/位置 | 依赖 | 时间盒/日 |
|---|---|---|---:|
| E03 | Grader 判真实任务目标、图片引用、结果/状态及失败归因，不只看 ACK/success | E02 | 0.75 |
| E04 | Reporter 汇总实际结果、分母、耗时/成本、安全及覆盖率，回溯原记录 | E03 | 0.5 |

先让同一任务贯通 Runner、Grader、Reporter，再扩集合，不能把先写完全部独立组件当作完成。

### 4.3 有限扰动与基线对照（第 3 日后半至第 4 日前半，1 日）

| 批次 | 唯一目标/位置 | 依赖 | 时间盒/日 |
|---|---|---|---:|
| E05a | 将 M6 已有布局/遮挡配置接入运行清单，记录一种实际环境扰动 | E04；复用已有场景配置 | 0.25 |
| E05b | 接入一种实际工具通信延迟/不可用故障，记录注入与回收 | E04；复用功能错误测试设施，边界评审 | 0.25 |
| E06a | 只根据 Dev 的一个调用问题冻结 B1 prompt/配置及声明差异 | E04；不看最终集 | 0.25 |
| E06b | Runner 配对执行 B0/B1 的同任务、初态与种子，保留费用及所有结果 | E01/E05a/E05b/E06a | 0.25 |

没有可改问题或没有正增益就如实报告，不故意弱化 B0。额外架构横评、多个模型及独立消融套件不作为本周前置。

### 4.4 最终运行与复核（第 4 日后半至第 5 日，1 日＋0.5 日预留）

| 批次 | 唯一目标/位置 | 依赖 | 时间盒/日 |
|---|---|---|---:|
| E07 | 按冻结集合实际重复运行，计算逐组完成率、配对百分点差值和任务族区间 | E06b；统计方法/预算固定 | 0.75 |
| E08 | 独立复核原始分子分母、版本和分组，导出报告/失败案例/复现说明 | E07 | 0.25 |

共 10 批，实施 4.5 日＋阻断修复预留 0.5 日，总计 **一周/5 个有效开发日**。样本量先做预算试跑再固定；次数不足就标注探索性范围，不能凭小样本承诺泛化。M6 与 M7 各自一周，不再合成一个 12.5–25 日实施阶段。

## 5. 拟议调用链与文件

主要改动在 `eval_harness/`、测评数据/manifest、必要运行配置和文档；实际 Agent 只在 E06a 存在有证据的有限改动。评测对象的创建、持有与退出在对应批次明确，不新增产品 Verification 或第二任务循环。

```text
[任务/版本/扰动配置] --实验协议与任务--> [Runner；待实现]
[Runner；待实现] --自然语言任务及预定输入--> [M6 实际有人主入口]
[Runner；待实现] --扰动请求--> [场景/通信注入器；待接入]
[M6 实际主链与 PX4/Gazebo] --状态、图片、检测输出、动作与开销--> [Episode artifacts]
[场景/通信注入器；待接入] --实际生效记录--> [Episode artifacts]
[Episode artifacts] --原始证据--> [Grader；待实现]
[Grader；待实现] --目标结果、预期通过、归因--> [Reporter；待实现]
[Reporter；待实现] --分组指标、样本量、差值与区间--> [JSON/可读报告]
```

## 6. 验证与交付

| 批次 | 最小评审证据 |
|---|---|
| E01 | M6 通过版本、判据、任务族和 B0 快照可核对；未见集合未参与开发。 |
| E02 | 真实入口及视觉链运行，有状态、媒体、费用、超时和清理证据。 |
| E03 | 能区分目标完成、正确停止、工具效果失败及证据不足；真值不泄露给 Agent。 |
| E04 | 指标回溯逐次结果，失败不移出分母，未知费用不填零。 |
| E05a | 布局/遮挡变化真实生效，参数与画面记录对应。 |
| E05b | 实际通信故障触发/回收记录，保留真实 Agent/Gate/PX4，替身另组。 |
| E06a | 一个有限 Dev 支持的 Agent 差异，工具、模型和 Safety 不变。 |
| E06b | B0/B1 配对键、顺序、版本和种子完整，重试不覆盖原失败。 |
| E07 | 各已承诺组有实际运行，指标/区间可重算，小样本和缺失配对明确。 |
| E08 | X 和百分点有原始证据、适用范围及复现命令，负提升照报。 |

结束必须交付普通/未见/扰动场景指标和基线差值，附样本量、95% 区间或无法有效估计的说明、耗时、成本、安全和失败案例。没有独立未见族或真实扰动时列为未完成，不能用功能通过率替代。

## 7. 止损、回滚与后续

到一周末仍阻断则列明缺失指标及原因，不补做新业务功能来转移目标，也不默认借用 RSI/面试时间。实验配置与注入可独立撤销，历史 artifacts 保留，M6 功能链回归不得受破坏。更多模型/架构/扰动及更大样本在已有报告后另排，不提前承诺正提升或统计显著。

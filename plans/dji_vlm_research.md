# 司空 2 Copilot VLM 部署核对

核对日期：2026-11-25。对象是用户截图中的 Copilot VLM 搜索，不将机载人车船识别、第三方机载算法或招聘方向当作该功能的部署证据。

## 已确认

[官方私有版多模态大模型部署文档](https://developer.dji.com/doc/priv-deployment-document/cn/capability-expansion/multimodal-large-model-deployment.html)明确支持两条服务器路径：将官方适配安装包部署到集群的大模型服务器节点，或配置外部 LLM/VLM 服务地址、模型名与 API Key。该配置覆盖多模态目标检测识别及 Copilot 远程控制。

官方适配路径的最低要求含 x86、128 GB 内存和 48 GB 显存；部署的是服务器模型服务。这直接证明私有版存在服务器侧推理路径，不能将其称为飞行器机载推理或遥控器本地推理。

文档分别配置 LLM 和 VLM；两者可指向同一模型服务，也可分开。当前文档列出自有模型的可行性推荐：通用服务器路径为 `Qwen3.8-27B`，信创 ARM/C86 场景为 `Qwen3-VL-32B-Instruct`；后者的支持表明确不含 Copilot。推荐型号并不证明公有云默认使用该型号。

## 未确认

所查官方部署文档与 [Copilot 使用手册](https://fh.dji.com/user-manual/cn/copilot-assistant/copilot-remote-control.html)未明确披露公有云 VLM 默认基础模型、权重版本，或官方适配安装包内部确切型号。不能把“支持接入的模型”写成“大疆默认使用的模型”。

公有云具体推理节点的拓扑、部署地域和所用模型，当前证据不足以逐项确认。应将“私有版服务器路径已确认”与“公有云具体实现尚未公开确认”分开报告；不能仅凭能力名称反推内部硬件。

## 对本项目的意义

本项目可采用相机图像传到地面/服务器模型服务的方案，无需先购买机载 GPU。该选项仍需单独验证图像传输、响应延迟、目标定位及失联行为；本次仅调查，不新增 VLM 或修改当前人物检测工具。
